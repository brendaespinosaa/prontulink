# Requisitos do Sistema – ProntuLink

## Requisitos funcionais

- Permitir a organização de informações dos pacientes.
- Disponibilizar informações clínicas para consulta.
- Apresentar dados de forma clara e organizada.
- Facilitar a localização de informações essenciais.
- Simular o acesso às informações por profissionais de saúde.

## Requisitos não funcionais

- Interface simples e intuitiva.
- Organização visual das informações.
- Facilidade de navegação.
- Proteção e privacidade das informações.
- Uso de dados fictícios durante as simulações.

## Observação

Os requisitos descrevem os objetivos previstos para o protótipo. Sua implementação deve ser verificada diretamente nas funcionalidades disponíveis.
