# Testes e Validação – ProntuLink

## Objetivo dos testes

Verificar a apresentação, navegação e funcionamento das funcionalidades disponíveis no protótipo.

## Metodologia

Os testes devem ser realizados utilizando exclusivamente dados fictícios, simulando situações de consulta e organização de informações clínicas.

## Cenários de teste

| Cenário | Verificação |
|---|---|
| Abertura do sistema | Verificar se o protótipo abre corretamente |
| Navegação | Verificar acesso às telas disponíveis |
| Visualização | Conferir a apresentação das informações |
| Organização | Verificar a disposição dos dados |
| Simulação | Avaliar o funcionamento das funcionalidades disponíveis |

## Resultados

Os resultados deverão ser preenchidos após a execução dos testes, registrando o comportamento observado, eventuais erros e ajustes realizados.

## Limitações

O ProntuLink é um protótipo acadêmico e não deve ser considerado um sistema clínico em produção. Não realiza integração com sistemas externos de saúde sem desenvolvimento específico.
